# Pre-submission review: "High-Throughput ECC2K-130 Walks on Blackwell GPUs"

Reviewed 2026-09-26 against the literature sweep recorded in
`aburan28/crypto-autoresearcher` (`docs/ecdlp-literature-review-20260926.md`,
`knowledge/frontiers/ecdlp/`). Verdict: **the core contribution is timely and
probably first-of-kind, but one issue blocks submission as written.**

## What checks out

- **`clmad` exists as described.** NVIDIA PTX ISA §9.7.1.5 defines
  `clmad.{lo,hi}.u64`, introduced in PTX ISA 9.3, requiring sm_80 or higher
  (read 2026-09-26). NVIDIA's announcement (Technical Blog, 2026-07-15)
  benchmarks only GHASH and GF(2^128) sum-check, with nothing on ECC or
  ECDLP. No academic paper using it for binary-field ECDLP was found.
- **The prior GPU number is 2010.** Bernstein et al., "ECC2K-130 on NVIDIA
  GPUs" (ePrint 2012/002), reports more than 63M it/s on a GTX 295. That is
  about 1,180 SM-cycles per iteration, against about 20 here (derived). No
  academic GPU Pollard-rho paper appears on ePrint or arXiv after 2019.
- The ePrint identifiers of the references already in `references.bib` are
  correct.

## Blocking issue: the measured walk uses cycle rule v1

`include/tablewalk.h` in the frozen candidate (`eccTagFruitless`) refuses only
two patterns: a step that undoes the previous one, and a pairwise 4-cycle.
The sibling repository's analysis of this same walk
(`aburan28/crypto`, `ecc2k130/WALK-CONSTANT.md`) enumerates what that rule
lets through:

- 24 four-step τ-relation cycles, from τ² + τ + 2 = 0;
- six-step pairwise cycles such as `a, b, c, −a, −b, −c`.

At `dpWeight = 32` these trap about half the trails. Priced end to end, the
table walk as built costs **4.85–6.26× the σ-walk per solve**. That
repository's HEAD carries a rule **v2**, which refuses negations up to four
tags back and checks the τ-relation (`eccTagFruitless(t, hist, m)`). v2 is
projected at 0.81–0.86× σ's cost, but no paired GPU run has been made.

Consequences for the manuscript:

1. The "≈1% of DP34 trails enter six-step fruitless cycles" estimate
   (§ collision quality) is inconsistent with that enumeration. It should be
   re-derived or replaced with a measurement.
2. 22.100934 B/s is a rate of scheduled slot updates on a walk whose
   useful-collision rate is unmeasured and, under v1, probably poor. The
   paper already avoids an effective-throughput claim. Reviewers will still
   read the headline as "5× faster than the campaign walk is useless if
   cycles eat it".

Pick one route before submission:

- **(a)** Port rule v2 into the kernel, re-run the five-sample confirmation,
  and add a collision-quality table: iterations to a useful collision on the
  scaled m = 41 and m = 83 curves (`ecc2k130/small`, `--curve 41/83`), and
  the undetected-cycle rate at m = 131 over at least 10^9 steps.
- **(b)** Lead with the campaign-compatible σ-walk (17.45–17.63 B/s), whose
  collision behaviour is Bailey et al.'s, with measured c = 1.08–1.10. Report
  the table walk as an arithmetic ceiling only.

## Related work to add

These are missing from `references.bib`. Identifiers were verified 2026-09-26.

- Bos, Kleinjung, Niederhagen, Schwabe. *ECC2K-130 on Cell CPUs.*
  AFRICACRYPT 2010; ePrint 2010/077. 749 cycles/iteration per SPU.
- Bernstein, Chen, Cheng, Lange, Niederhagen, Schwabe, Yang. *Usable
  assembly language for GPUs: a success story.* ePrint 2012/137. How the
  2010 kernel went from 25M it/s (nvcc) to 63M it/s.
- Fan, Bailey, Batina, Güneysu, Paar, Verbauwhede. *Breaking elliptic curve
  cryptosystems using reconfigurable hardware.* FPL 2010;
  doi:10.1109/FPL.2010.34.
- Bernstein, Engels, Lange, Niederhagen, Paar, Schwabe, Zimmermann. *Faster
  elliptic-curve discrete logarithms on FPGAs.* ePrint 2016/382. The
  117.35-bit binary record and sect113r2.
- Wenger, Wolfger. SAC 2014 (ePrint 2014/368, a 113-bit Koblitz curve) and
  JCEN 2016 (ePrint 2015/143, sect113r1).
- Bos, Kleinjung, Lenstra. *On the use of the negation map in the Pollard rho
  method.* ANTS IX, 2010; doi:10.1007/978-3-642-14518-6_9. The fruitless-cycle
  analysis this walk needs.
- Gallant, Lambert, Vanstone. *Improving the parallelized Pollard lambda
  search on anomalous binary curves.* Math. Comp. 2000. The √(2m) Frobenius
  factor.
- Montgomery 1987, for simultaneous inversion. It is already cited in the
  ECDLP manuscript but not here.
- Context for GPU EC arithmetic: gECC (ACM TACO 2025; arXiv 2501.03245), and
  the community GPU kangaroo solvers (JeanLucPons/Kangaroo, RetiredC/RCKangaroo).
  Cite these as software; they are not peer reviewed.
- NVIDIA Technical Blog, 2026-07-15: "Building Faster Cryptography with
  Carryless Multiplication in NVIDIA CUDA 13.3". The only other published
  `clmad` benchmark.
