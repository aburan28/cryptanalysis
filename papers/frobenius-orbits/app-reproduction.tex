\section{Reproduction}
\label{app:repro}

Every number in the paper is footnoted to a file in one of three
repositories: this library (\thislib, paths without a prefix), the
sibling Rust library (\sibling, prefix \texttt{crypto:}) and the research
ledger (prefix \texttt{crypto-autoresearcher:}). The artefacts that
reproduce each section are:

\begin{description}[leftmargin=1.4em,itemsep=0.2em,style=nextline]\raggedright

  \path{crypto:src/cryptanalysis/koblitz_fast.rs} (\texttt{FrobeniusCanon}),
  test \path{the_least_rotation_partitions_exactly_as_the_squaring_chain};
  cost: \path{crypto:examples/koblitz_fold_cost.rs} with argument \texttt{61}.
\item[Section~\ref{sec:canonicalization}, variant B]

The factor bases are archived under \path{experiments/fb-archive/};
CI fails when a committed result cites a base digest that is not
archived. The normal element (or the basis-change tables) used to
name orbits is part of each run's protocol and must be archived with
the base (Section~\ref{sec:conventions}).
