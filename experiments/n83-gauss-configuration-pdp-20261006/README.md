# N83 CryptoMiniSat Gaussian-policy gate

This gate reuses the exact fully pinned N83 slope-witness XCNF generated by
[the preceding pilot](../n83-slope-witness-pdp-20261006/README.md). Its input
hash, binary hash, source hashes, two solver configurations, and resource
limits are frozen in [protocol.json](protocol.json). The existing solver
returned `BOUNDED_UNKNOWN` even when all five raw factor points were given.
The circuit itself has a verified complete Boolean model and independent Sage
group replay; this gate asks whether CryptoMiniSat's Gaussian policy can find
that planted model under the same cap.

The first variant raises the Gaussian matrix row and column limits from the
installed binary's displayed defaults of 2,000 and 1,000 to 10,000 and
15,000, with at most ten matrices. The second uses the same limits and
disables automatic Gaussian shutdown. Each run is guarded at 120 solver
seconds, one million conflicts, 900 process-tree wall seconds, and 2 GiB
process-tree RSS. Failed attempts remain rows. A SAT result requires full
CNF/XOR, independent group, and checked Sage replay before any next stage.

The input is fully pinned with private factor points. Even a verified SAT
would be a positive control only; it is not ordinary-query yield, an `IC1`
candidate, a target DLP, or a speedup.
