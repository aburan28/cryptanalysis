# Q1508: exact pair blocking exposes a second N83 first pair at 53–56 thousand CNF/XOR calls

An exact exclusion of the first 166-bit coordinate pair changes the chained-S3
WDSat search path on two frozen ordinary N83 target points. The next distinct
pair appeared at branch 27 after **53,493** and **55,817** combined CNF/XOR
calls, respectively. Its second leaf had no rational lift on either point, so
the exact factor-base filter rejected it before a complement scan. The first
pair on each point had two rational, subgroup-usable base leaves; its four
signed complements were each fully scanned against the exact base and had
zero hits. This is a measured pair-enumeration handoff and a measured
ordinary relation screen.

The base is the exact W≤5 point set with **B=30,977,592** usable points before
folding and **K=186,612** signed-Frobenius columns. The eight complete scans
charged **619,551,840 = 2^29.207** batch multiplication calls, excluding
batch-inversion internals, first-pair SAT, key construction, and filtering.
Both searches stopped on the first-pair marker; the second-pair rows do not
claim a complete S3 solve. The two-point observation does not estimate
ordinary relation yield or a complete N83 decomposition cost.

The N131 W≤6 exact base has B=6,559,634,788. Transferring this scanner's
zero-hit formula gives **10B = 65,596,347,880 = 2^35.933** batch
multiplications for one complete four-sign scan, **5.333 bits above** the
prior 2^30.6 per-decomposition allowance for a 2^61 full-solve budget. This
comparison charges only one scanner stage and assumes that full four-sign
scan is performed. Q1505's conditional independent-uniform-first-pair
relation-supply model remains **2^123.289** batch multiplication calls,
62.289 bits above 2^61; this experiment's target-dependent search order
does not justify replacing that model with an empirical full-solve estimate.
The complete charged N131 solve exponent stays null until ordinary relation
yield, novel rank, matrix work, target handling, and a verified target are
measured together.

The exact exclusion is encoded as **164 three-literal CNF clauses with 163
auxiliary variables**. WDSat's CNF kernel dispatches only clauses of length
one through four. Two failed preflights are retained: a 166-literal clause
at the XCNF end and then before the XOR rows both returned the original
pair. A separate mask-marker mismatch was caught before scanning. The
three-CNF chain is verified to exclude the recorded assignment, the frozen
XCNF is regenerated byte for byte, each distinct pair is replayed through
the curve, subgroup and exact base filter, and all eight scanner outputs,
complement coordinates and hashes are checked by the validator.
