# Next experiments selected by the complete-query evidence

1. **Qualify the successful-query comparison on an isolated host.** Keep these
   inputs, limits, phase boundaries and checker arms fixed. Rebuild natively and
   attach the repository isolated-benchmark service receipt. Retain every failed
   isolation/noise gate. Do not infer CPU speedups from the local timing table.

2. **Profile the producer on the thirteen budget-limited fixtures.** They never
   reach certification, so additional checker scheduling cannot improve their
   accepted outcome. Bind counters for symbolic preprocessing, row construction,
   monomial lookup, pivot/reduction work and certificate construction. Compare
   representation or scheduling changes at identical work and memory limits,
   preserving exact fresh-input and independent-certificate checks. Increasing
   the budget alone is not an algorithmic improvement.

3. **Reduce complete-query overhead on accepted fixtures.** The retained phase
   records include extraction and independent curve replay, which are material
   on small cases. Evaluate generic bounded Boolean root extraction and native
   equation checks separately, retaining an independent mathematical oracle.
   Keep fixture construction and reusable layouts outside the query interval;
   never cache target answers or omit correctness checks to improve the timer.

4. **Keep GPU and structural experiments evidence-driven.** For GPU work, carry
   a complete single-query interval through packing, transfers, matrix work,
   certificate checking and output verification. For proposed F6 methods, test
   precisely stated layout/separator or structured-update conditions against
   F4 and signature/evaluation baselines, including hard failures. Existing
   symbolic reuse and proof reclamation do not prove a better asymptotic bound.
