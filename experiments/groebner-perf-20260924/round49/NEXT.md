# Follow-up experiments

The current implementation remains an explicit experiment. Complete-query performance and device coverage must be reported separately from row-witness correctness. The frozen measurement plan governs promotion; failures and denied admissions remain results.

1. Restrict the additional GPU projection to linear-pivot rows of the first RREF. Every quadratic-pivot row has a quadratic pivot column that is zero in every other row. Its coefficient must therefore be zero in any affine consequence. After excluding those rows, at most `y <= 10` variable-pivot rows remain, together with a possible constant-one row. Compute the quadratic kernel of this restricted subsystem while carrying original-equation witnesses. Existing quadratic pivot columns can be skipped. Prove and test the rank accounting (`original quadratic pivots + restricted quadratic rank`) and compare the entire affine consequence space, not a chosen basis. This is a linear-algebra simplification, with no novel asymptotic Gröbner claim.
2. Consume a useful affine certificate before reconstructing the lifted particular solution and nullspace on the host. The current host still reconstructs that lifted space before calling the projection constructor. A complete partial-affine certificate could make that work unnecessary on handled branches. Preserve exact root completeness, staged rollback and all work/assignment budgets; avoid a duplicate projection attempt on fallback. A full-rank affine row system with a valid root needs an explicit complete certificate, not just one discovered root.
3. Reduce additional output traffic by returning only the affine row witnesses and reconstructing the small row coefficients while assembling the proof, or by a compact representative layout. Charge every host parity, map lookup and byte. The current uncompressed output is deliberately simple and directly auditable; the 27-variable shape adds 22 MiB.
4. Independently verify GPU-produced affine identities in batches only if their conversion and synchronization costs improve one complete query. The independent checker must continue rebuilding fresh coefficients from the original ANF in separate storage. Producer-derived tables, ranks and pivot rows cannot substitute for this reconstruction.
5. Address the 64 MiB coefficient-table cap using a separate streamed or degree-compressed checker. This limit still prevents the straightforward 30-variable shape; GPU affine projection does not remove it. Derive a complete coverage argument and explicit memory/recomputation costs before claiming a scaling improvement.
6. For a structural “F6” proposal, freeze applicability conditions and compare separator decompositions, symbolic elimination and structured coefficient families with exact fallback and independently checked certificates. A new asymptotic claim requires a proof and difficult counterexamples. Any eventual IC performance result requires a fully specified candidate and a previously unseen single public target, verified through scalar recovery and paired with rho on the same point and resources.
