# Independently checked fixed-block symmetry

This implementation changes only the complete Boolean basis checker. It accepts the existing round44 constant-prefix plus tagged-affine record protocol. Its producer, input law, proof payloads, complete root list and reduced basis are unchanged. The checker has a portable CPU implementation; a Metal producer may feed the same checker. The checker itself has no GPU kernel.

For an even fixed-variable count x=2k, let sigma exchange the low and high k-bit blocks, leaving all residual variables unchanged. The checker independently clears and XOR-scatters the original packed ANF into its feature-major coefficient table. Before specializing that table, it compares each present input term's aggregate coefficient with the aggregate coefficient of its exchanged monomial, in every equation limb. Zero input coefficients and monomials fixed by sigma need no comparison. Duplicate and canceled terms remain valid inputs: comparisons use the aggregate table, not an individual term coefficient.

This support-only guard is exact. If the two aggregate polynomials differ under sigma, some coefficient is nonzero on at least one side. That nonzero aggregate coefficient has at least one nonzero occurrence in the original input, so the mismatch is visited. Thus a successful guard proves each original equation F satisfies F(a,b,y)=F(b,a,y). Every target receives a fresh scatter and guard; no target coefficients, decisions or answers are cached. The earlier dense guard and its passing evidence are retained with the local physical experiment artifacts.

After all existing proof shape, padding, order and overlap checks, the checker pairs each branch with its exchanged branch. Diagonal branches remain singletons. It reuses a checked representative only when the two branches carry identical constant witnesses, identical multiplier witnesses, identical tagged affine witnesses, or neither carries a witness. Record headers retain their own branch identities. A missing, different, or differently tagged certificate causes full independent checking of both branches; it does not cause rejection by itself. Invalid certificates still fail the original identity checks, including identical invalid certificates on both sides.

The representative has identical specialized original equations and identical witness consequences. Consequently its contradiction result, reconstructed affine space, or exhaustive residual solution count applies to the paired branch. Counts are weighted by two for a reused pair. Every claimed root is still checked directly against the original ANF; the root list must be distinct, sorted, and have the exact full count. The existing basis evaluation, Boolean staircase cardinality and reducedness checks remain mandatory. A representative-only root list fails completeness.

The auxiliary branch-offset and reuse arrays use 5*2^x bytes, separately reported and capped at 8 MiB. Allocation or shape failure preserves the original checker. The guard and proof-comparison budget is 67,108,864 abstract work units: one per input occurrence, one per aggregate coefficient comparison, one per initialized array entry, one per record indexed, one per candidate proof pair and one per compared proof word. It is not a FLOP count. Budget exhaustion abandons all reuse flags for that query, including flags already prepared. Attempted guard work remains recorded. Existing table, proof, root, basis, affine-work and assignment limits remain in force.

Counters distinguish logical coverage from actual work. Branch, contradiction, enumerated-branch, root and extended-contradiction counts cover both sides. Assignments, partial records/rank/work, multiplier parities and multiplier payload words count work physically performed. Separate derived and avoided counters reconcile them with the existing independent checker. Guard time is nested within specialization time and must not be added twice. Auxiliary allocation is target-independent; the fresh guard, matching and verification belong inside complete-query timing.

This is an exact symmetry optimization for the supported Boolean split, not a general F4/F5 complexity improvement. The complete solver remains bounded and may return inconclusive. Validation timings are unqualified diagnostics. There is no new elapsed-time speedup claim or automatic dispatch change.
