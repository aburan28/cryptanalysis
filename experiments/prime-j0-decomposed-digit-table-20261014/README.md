# One-table unit-basis digits for the 17-position `140−τ` format

The selected digit `a+bτ` has the exact two-component form `(a+b)−b(1−τ)`. In the norm-19,183 radix, both signed component magnitudes are at most 92; the terminal coefficients after 17 steps are at most 90. The same positive-multiple table at each position serves both components. One bucket accumulates the ordinary multiples, another accumulates the `(1−τ)` multiples, and a single unit-map rotation converts the second bucket before their final addition.

This changes the direct point payload from **3,714,752 to 105,856 bytes**. The native implementation retains **145,808 bytes**, versus 4,178,836 bytes for the 17-position orbit table, a 28.7-fold reduction. Its exhaustive 19,183-residue test, independent-binary 128-case native holdout, and 388-case independent affine replay all passed. The frozen 96-pass Tier 1 panel found a **0.7366 paired split/orbit hot-table throughput ratio** with repeat-bootstrap interval **[0.7345,0.7387]**: the compact table is slower online but prepares 8.1 times faster on the same allocation.

The parent `140−τ` format fixes the scalar representative, selected digit, 17-step recurrence, curve, generator, and 128-scalar fixture. This experiment changes the point-table encoding and accumulation only. The split basis is `(1, 1−τ)`; with `x=a+b` and `y=−b`, `a+bτ=x+y(1−τ)`. The point map for `1−τ` is the secp256k1 `j=0` unit map. Both components use the same table row of nonnegative multiples of the position base; negative coefficients flip the affine `y` coordinate. Each bucket receives at most one addend per component per position. The second bucket is rotated once after accumulation, then joined to the first.

The exact screen evaluates all 19,183 selected digits and all 22,057 integer terminal pairs inside the proved norm radius `78²`. It finds digit coefficient maxima `92,92` and terminal maxima `90,90`. The 24 oriented bases formed by two norm-one units each have a sum of digit coefficient maxima at least 184; `(1,1−τ)` attains 184. The payload count is `64×(17×92+90)=105,856` bytes of nonidentity points. Native retained bytes additionally charge identity slots, the 9,592 selected digit pairs, row storage, and constants.

`UnitBasisSplit.split_value` proves the scalar identity for any integer τ eigenvalue. `norm_digit_coefficient_bounds` proves the 92 limit from digit norm at most 6,348, and `selected_digit_coefficient_bounds` applies it to the parent's canonical-residue selector. `norm_terminal_coefficient_bounds` proves the 90 limit from terminal norm below `78²`; the parent's `NearestOrbit19183Complete.canonical_scheme_terminal_bound` supplies that norm condition for every selected scalar trajectory.
