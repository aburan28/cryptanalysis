# Direct 2-adic orbit atlas experiment

The [proof](PROOF.md) gives a dense arithmetic index for the six-unit
orbits in `(Z/1024Z)^2`. The candidate replaces the quotient atlas's
six-image minimum, 1,048,576-bit canonical-class mask, and rank
directory with valuation, parity, sign, and a level offset. It keeps
the existing 83,051-seed tau cover, point tables, exact terminal
atlas, 12 full radix-1024 windows, and final XYZZ bucket procedure.

Construction and validation order:

1. Freeze the indexing algorithm and independently enumerate all
   `2^20` residues, their six-unit orbit assignment, and exact unit
   transform.
2. Reindex the quotient codes with this formula and independently
   decode every residue. Check digit congruence, norm, and exact
   equivalence to the earlier quotient decoder. Preserve binary
   assets and source hashes.
3. Commit the construction and input law before drawing a new
   4,096-scalar panel, disjoint modulo the subgroup order from prior
   panels.
4. On that panel, replay the adic atlas and quotient control on the
   same scalars. Check integer reconstruction, independently computed
   group points, mixed additions, tau images, and gauge rotations.
5. Materialize a separate source-pinned native mode, retain the old
   quotient and direct-code modes as controls, and run targeted and
   full-suite correctness checks. Queue a serial Linux correctness
   replay against the exact source commit.

The native retained size includes all point slots and atlas bytes.
Any speed claim requires paired full scalar evaluation in a host-level
isolated environment under `docs/ISOLATED_BENCHMARKS.md`; local and
current RunPod timings are diagnostics only.
