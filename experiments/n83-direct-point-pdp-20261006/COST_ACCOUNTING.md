# N83 direct-point pilot: measured cost boundary

This is a source-bound **stage diagnostic**, not a complete IC candidate or a
single-target DLP benchmark. The machine-readable [ledger](COST_LEDGER.json)
is regenerated by [make_cost_ledger.py](make_cost_ledger.py) from immutable
receipts. It binds each run to its receipt and XCNF hashes, verifies that the
four ordinary raw fibers represent the same public subgroup target, and
checks every exclusive phase sum in integer nanoseconds.

The exact measured base has **B = 1,936,390** distinct usable projected
points and **11,665** signed/Frobenius-folded columns, as recorded in the
[geometry receipt](../hamming-ic-e2e-20260929/runs/n83_full_w4_geometry_v1/progress.json).
These counts describe the base, not successful relations. The five-summand
multiset count divided by subgroup order is 93,832.98, a combinatorial
diagnostic rather than a measured solver completion probability.

For each direct-point attempt, the exclusive measured process-tree wall
ledger is

`T_outer = T_circuit_build + T_XCNF_write + T_solver + T_inner_other + T_outer_other`.

`T_inner_other` is the inner-run residual after build, write, and solver;
`T_outer_other` is the watchdog/launch residual. These residuals are measured
by subtraction from nested monotonic intervals, never set to zero. The table
rounds to milliseconds for reading; [COST_LEDGER.json](COST_LEDGER.json)
retains exact nanoseconds and asserts exact sums. All runs used one
CryptoMiniSat thread, a 120-second internal solver limit, one million
conflicts, a 900-second outer cap, and a 2 GiB process-tree RSS cap.

The four ordinary fibers are four related raw preimages of **one** frozen
subgroup point. They took 596.723 seconds in sequential exploratory process
wall time, including 588.131 seconds in solver calls. There were zero
verified witnesses within the frozen limits. They are not four independent
ordinary queries; no binomial relation-yield interval or novel-row rate can
be estimated from this panel. A solver timeout is censored, not UNSAT.

The pinned-mask SAT result passed all CNF/XOR rows, integer-field group
replay, and [checked-Sage replay](runs/sign_enum_v1/sage_replay.json). The
17 UNSAT reports do not have independent proof certificates. The expanded
small-field test checks every finite target over GF(2⁵) for one fixed factor
x-pair: four reachable targets replayed, while all 39 others returned UNSAT.
That is a correctness control for the regular circuit, not N83 coverage.

The exact IC one-target online interval would charge all target-dependent
queries, failed PDP attempts, relation checks, descent, and scalar replay
after reusable base/index/log preparation. No factor logs, final relation
matrix, target descent, recovered scalar, or paired same-point rho run exists
here. Therefore `IC_online`, `rho_online`, cold total, operation-normalized
cost, cost per useful row, and speedup are **unknown** (`null` in the ledger).
The host lacks an isolation receipt, so its CPU timing ratios would remain
exploratory even if two complete methods were available.
