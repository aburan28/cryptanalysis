# Full quadratic rank for N41 suffix output and both seed sums

**The frozen N41 two-free-pair source has full degree-two Boolean evaluation rank in its suffix-sum x coordinate and both pair seed sums.** A 1,379-row certificate spans all **1,379** squarefree monomials of degree at most two in the 40 variable x bits and twelve seed bits. Consequently, no nonzero polynomial in that declared feature space vanishes on every valid suffix orbit. This removes a proposed universal quadratic seed-bin condition from the target-coupled search options for this exact geometry; the already measured finite-support bin filters remain valid.

The instance is `EC1N41Ckb1h7d5e80d3c4d0` on `y²+xy=x³+1` over `GF(2)[t]/(t^41+t³+1)`, subgroup order `549756390943`, with four W6 rotations `0,10,20,30`, actual factor-base size **B=256**, and **K=26** folded columns. The last two pair domains at rotations `20,30` contain **3,167,136** distinct-column group assignments and **1,583,568** inverse-sign x orbits. The [prior exact source census](../n41_seed_bin_quadratic_filter_20261009/RESULT.md) stores each orbit as its two nonzero six-bit seed sums `(s,t)`, x coordinate, and exact pair-state indices in [`x_orbits.bin`](../n41_seed_bin_quadratic_filter_20261009/x_orbits.bin). Every stored x has low bit zero. This study uses the remaining **40 x bits** and all twelve seed bits as independent feature variables.

For a valid suffix orbit, form

`v=(x >> 1) | (s << 40) | (t << 46) ∈ {0,1}^52`.

The feature vector is the evaluation of `1`, every `v_i`, and every `v_i v_j` for `i<j`. Its dimension is `1+52+C(52,2)=1,379`. If these vectors have full rank on any valid subset, every degree-at-most-two Boolean polynomial that is zero on the entire source must have all coefficients zero. The [producer](rank.py) froze the source hash and a deterministic shuffled row order, then stopped once its high-bit Gaussian pivots reached full rank. It examined **1,383** source rows and retained the **1,379 independent rows** in [witnesses.json](witnesses.json), drawn from **1,162** seed-bin pairs.

The [independent audit](audit.py) enumerates the monomial basis separately, uses the opposite low-bit pivot direction, and obtains rank **1,379** from those witness rows. It also reconstructs both exact 1,956-state pair domains from the archived curve geometry and replays *every* witness: pair indices, seed sums, disjoint folded columns, canonical inverse-sign orbit choice, and the curve sum's x coordinate. The earlier checked-Sage census independently recounted the complete suffix support; the [audit receipt](audit.json) binds that source.
