`(1+p²)c² + pc + s² = 0`.

With `z=pc`, this becomes `z²+z=(c+s)²`. The odd-degree half-trace yields both possible `z` values when the trace condition holds. For fixed `s`, the map `a ↦ a²+sa` on the 18-dimensional W18 space has kernel `{0,s}` and rank 17, so a linear-image inverse tests each candidate `p` and recovers both source masks. The oracle checks source membership, folded-column distinctness, the pair equation, and rotation after the inverse. Distinct source columns exclude the identity pair, so the accepted pair-output predicate has nonzero `c`.
