# Seventeen-position `140−τ` orbit radix

The prime-norm radix `140−τ` reduces the fixed-base recoding to **17 positions** and produced a **1.0232 paired hot-table throughput ratio** against the 18-position norm-12,211 rolling format on a frozen 128-scalar, 96-pass Tier 1 RunPod panel. A directly paired panel against the 16-position norm-35,533 format measured a **0.9696 reference/candidate ratio**, placing this format between the faster, larger 16-position table and the smaller, slower 18-position table. All 96 arms and 48 pairs in each 96-pass panel verified, and every adjacent A/A control passed [0.90,1.11]. The 17-position native table retains 4,178,836 bytes, compared with 2,448,196 and 6,829,948 bytes for the 18- and 16-position tables. Table preparation is charged separately. These are sustained hot-table throughput measurements on one Tier 1 allocation; a one-call latency study remains separate.

For `τ²−3τ+3=0`, the radix norm is `140²−3·140+3 = 19,183`. The selector checks two residue lifts and three centered `b` values per lift, minimizing `(norm, |b|, |a|, a, b)`. The exact screen verifies all 19,183 residue congruences, sign and six-unit covariance, and the global minimum for all 9,592 sign-canonical residues under the norm-derived `|b| ≤ 93` bound. Its maximum digit norm is 6,348. The 17-step contraction ends below norm `78²`; the digit table has 3,198 six-unit orbit seeds and the terminal table has 3,677.

The affine replay reconstructs each point from window bases `πⁱG`, six-unit orbit actions, and the terminal point, then checks it against independent binary scalar multiplication. It includes the existing 128-case fixture and 260 fresh or boundary scalars. The native overlay applied to frozen parent source SHA-256 `858089fac6083f123c4a9e86afe9cef9db9d24dfdc78df3546d4bed74165e52e`, producing source `e195374c4e6fde368bdba106c769c6335cd319f9f5547e8e2291089fe055335e` and release binary `5b6e9eaf792dafb0d9863a7d04c2dbe29b5156ea0af1f7e3e92b0094fbbf24a5` on the RunPod Linux pod. Its exhaustive 19,183-residue test and 128-case independent-binary holdout passed. The retained table is 4,178,836 bytes including metadata. The first remote test command recorded a `cargo` PATH failure; the corrected absolute-toolchain run passed, and both logs are preserved in the pending panel artifacts.

The first Tier 1 panel paired this binary with the 18-position rolling binary on the same frozen 128 scalars, 64 passes per arm, 16 alternating repetitions, and adjacent A/A gates. All 96 arms and 48 pairs verified with stable artifacts. Its descriptive paired median reference/candidate throughput ratio was 1.0271, with repeat-bootstrap interval [1.0173,1.0365]. The first repetition's preceding A/A ratio was 1.1362, exceeding the prespecified [0.90,1.11] gate; the qualified comparison is therefore **unknown**. This failed gate and every raw arm are retained. Mean online costs were 12.46 and 11.98 microseconds per scalar in that censored panel; mean table preparation was 497 and 734 ms, respectively, outside the online timer. The 96-pass panel was frozen to test the effect of a 50% longer interval under the same allocation and A/A gate. The unchanged native CLI rejects 128 passes, and that failed preflight is preserved as a source artifact. One-call latency requires its own A/A-gated panel.

The 96-pass panel completed all 96 arms and 48 pairs with stable artifacts and no A/A failures. Its paired median reference/candidate ratio was **1.0232**, with repeat-bootstrap interval **[1.0169,1.0308]**. Mean online costs were 12.21 versus 11.93 microseconds per scalar over 12,288 operations per arm. Mean target-independent table preparation was 497 versus 735 ms. The 17-position table retained 4,178,836 bytes versus 2,448,196 bytes for the 18-position reference. The bootstrap interval describes repetition variation on one cloud allocation and frozen scalar law.

The direct 16-versus-17 panel used the same 128-scalar law, 96 passes, 16 repetitions, CPU pinning, and A/A gate. Every arm verified, all 48 pairs were valid, and no A/A gate failed. The median ratio of 16-position reference throughput to 17-position candidate throughput was **0.9696**, with repeat-bootstrap interval **[0.9671,0.9762]**. Mean online costs were 11.60 versus 11.92 microseconds per scalar. Mean target-independent table preparation was 1,257 versus 730 ms, and retained native tables were 6,829,948 versus 4,178,836 bytes. The paired interval is below one, so the larger 16-position table was faster on this workload and allocation.
