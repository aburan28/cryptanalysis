# Deferred unit-class affine batch tree

This variant groups the signed radix-14 lookup points by their order-three x-rotation class. It uses batched affine additions across all 128 scalar outputs to sum each class, rotates only the three class totals, then uses batched affine additions to join those totals. The parent affine-layer tree rotates selected points individually. Deferring the rotations reduces x-constant multiplications on selected leaves but adds a fifth inversion layer and three times as many class lanes during the first tree stage.

`native_affine_unit_overlay.py` is guarded by the exact parent source hashes. The resulting front source is SHA-256 `03273b81d89141d5bfc29f02045a2f7fdbe49116a7f0581301725d07f132fe25`, arithmetic source `fba2650703f4512535c1e28b19ab1ef3ef2d44dcfbff032522ac31974bd63008`, and release binary `e10fa67ad95e035c3faccc2757504c4440640ddac4348bf6547670fe3e21df58`. The Linux release test matched 128 independent frozen scalars against the parent affine-layer output, fixture points, and an independent binary multiplier, plus the identity case.

The direct, sequential A/B/A sizing screen verified the same 12,288 outputs per invocation and retained the same 26,035,988 table bytes. Online intervals were **51.651204 ms** for the parent affine tree, **57.222970 ms** for the deferred unit-class tree, and **51.789285 ms** for the parent again. The candidate/reference ratio in this screen was 1.106, indicating more time for this exact layout. These timings are exploratory: the direct screen has no pinned runner A/A noise receipts. It falsifies this layout as the next high-priority speed candidate, so no qualified panel was launched. All test, build, and diagnostic logs are in `unit-class-diagnostic.tar.gz`, SHA-256 `09baeb75d9ac7632106d993ffa1b016df5ec1a045fb40f42f5a34f994b8663f8`, and unpacked beside it.

`UnitClasses.three_class_delayed` proves the group-level identity that moving an additive order-three endomorphism from each class element to the class sum preserves the three-class expression. It quantifies over all three point lists and requires exactly `tau(0)=0` and additivity of `tau`. `check_lean.sh` builds the theorem with Lean 4.34.1; `#print axioms` reports only `propext`. The parent `AffineLayer.layers_preserve_sum` theorem supplies the tree-reduction step under an exact affine pair-addition hypothesis. The native holdout checks the concrete Rust field/curve bridge; a Lean model of that implementation remains open.
