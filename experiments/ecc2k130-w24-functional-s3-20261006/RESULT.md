# Functional W24/m6 SAT: planted formula is satisfiable, bounded search times out

The functional inverse and complete S3-root circuit did **not** clear the
preregistered planted solver gate. CryptoMiniSat found no model before the
external 30-second planted cutoff, so the frozen ordinary ECC2K-130 target
was **not run**. A separate certificate proves that the exact timed-out XCNF
is satisfiable by the known six-point relation: an independent reader found
zero violations across all 2,184,112 CNF clauses and 956,409 native-XOR rows,
and checked Sage confirmed the group relation and four S3 roots. The result
isolates a bounded *search/formulation* failure for this exact encoding; it is
not UNSAT, zero natural yield, a logarithm, or an IC/rho comparison.

The [initial protocol](PROTOCOL.md), [hash-pinned config](CONFIG.json), and
[planted-only witness protocol](WITNESS_PROTOCOL.md) were each committed and
pushed before their respective runs. This branch is stacked on the original
[source W24/m6 SAT control](../ecc2k130-w24-natural-pdp-20261005/RESULT.md)
and uses the same source W24 prefix (`B=16,772,828` actual usable subgroup
points; 8,386,414 sign columns), six summands, first six published control
masks, four ordered `[4]` fibers, one primary workload ID `eee7f6ee5f6b`,
CryptoMiniSat 5.14.7 binary, seed zero, one worker, and 4 GiB monitored RSS
cap. Inverse witnesses are fixed 131-bit field functions of the masks; each
of four S3 intermediates is a function of earlier coordinates and one root
bit. Both `B=0` and `B=1` quadratic branches are encoded. Independent field
controls checked 12 inverse/half-trace values and regular, `B=0`, and `B=1`
root cases before the measured run.

The [profile](runs/profile/receipt.json) and strict
[planted run](runs/planted/receipt.json) generated byte-identical XCNF,
SHA-256 `1e12c05b798af29e5ccbde939a618caffcd4b5605a19111b6153a0aaff136e6a`.
The strict run built it in 21.083 seconds; the monitored solver process ran
30.314 seconds, was killed at the external wall limit (exit `-9`), returned
no final solver status, and produced no model. Its polled RSS peak was
432,914,432 bytes, below the 4,294,967,296-byte cap. The profile build took
50.598 seconds on the same unisolated host; these variable wall times are
exploratory, with no controlled performance ratio. Independent
[checked-Sage replay](runs/planted/sage_replay.json) verified the exact curve,
control points and fiber but found `NO_MODEL_REPLAYED`.

The first planted invocation exposed a sandbox denial of the required live
`/bin/ps` RSS poll. Its [raw output and invalid-attempt receipt](runs/monitor-denied/attempt.json)
are preserved; the solver text ended `INDETERMINATE`, but there was no valid
memory-monitored interval and it is excluded from the bounded comparison.
The runner now catches monitor `OSError`, kills its child and records a
`memory_monitor_failure` rather than losing the failure. The strict rerun used
verified live RSS access and exactly the same formula bytes.

For the post-timeout diagnostic, the known raw group chain selected root bits
`[0,0,0,0]`; all four planted roots were in the regular quadratic branch.
The [packed assignment](runs/witness/assignment.bin.gz) contains one truth bit
per XCNF variable (210,539 uncompressed bytes). The
[independent XCNF verifier](runs/witness/verification.json) checked every
clause and XOR row of the archived timed-out formula with zero violations.
The [independent Sage group replay](runs/witness/sage_group_replay.json)
recomputed the minimum-y raw points, selected fiber, root equations,
partial-sum coordinates and `[4]` target, returning
`PASS_PLANTED_GROUP_WITNESS`. This proves *planted satisfiability*, not that
the SAT solver can recover an assignment under the budget.

The evidence argues against simply replacing free inverse/intermediate bits
with this larger functional XCNF at N131. It does not rule out compact S7
elimination, pair-root indexing, crossbred/F4/F5, an improved SAT encoding,
other factor-base policies, or smaller-field end-to-end studies. The next
N131 solver gate should first reduce formula size or exploit target-adaptive
structure, then pass a planted and ordinary-query control on the same frozen
workload. Full factor-base construction, natural relation yield, useful rank,
final matrix cost, target descent, verified logarithm, one-target online wall
time and paired rho remain unmeasured. `candidate_id` and speedup remain
`null` in [RESULT.json](RESULT.json).
