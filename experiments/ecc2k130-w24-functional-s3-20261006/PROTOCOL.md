# Frozen functional W24/m6 S3-root SAT gate

This is a controlled follow-up to the [source W24 SAT control](../ecc2k130-w24-natural-pdp-20261005/RESULT.md). It tests whether removing both free witness classes found in that control lets the same CryptoMiniSat binary recover a planted six-point relation and then attempt the already frozen ordinary target. The proposal is `Q1420`; this is a PDP-stage experiment, not an end-to-end `IC1` candidate or IC/rho speedup claim.

The curve, source W24 prefix, six summands, four ordered cofactor-four fibers, base-selection files, and primary one-target workload `eee7f6ee5f6b` are exactly those of the parent. The source base has `B=16,772,828` usable subgroup points and 8,386,414 sign columns. The planted input uses the first six published source control masks in their published order, minimum-encoded-y raw lifts, their raw group sum, and its selected fiber. The sole ordinary input is public source point zero of the primary workload. Neither the known target scalar nor a favorable target fiber may enter the formula.

For every leaf mask, form the same 24-bit W24 coordinate `w` and linear half-trace coordinate `u` as in the parent. Replace the 131 free inverse bits by a *functional* fixed addition-chain inverse `w^(2^131-2)`: build `b_(2k)=b_k * b_k^(2^k)` for `k=1,2,4,8,16,32,64`, then `b_130=b_128 * b_2^(2^128)` and square. Impose `Tr(w^-1)=0` exactly and retain the original nonzero/prefix mask constraints. Check the addition chain with independent field arithmetic before a solver run.

Replace each of four free partial-sum `u` rows by one root-choice bit and the exact characteristic-two S3 quadratic. For two current values `u1,u2`, put `w_i=u_i^2+u_i`, `B=w1*w2`, `A=B+1`, `C=(u1+u2)^2`. The equation is `A*z^2+B*z+C=0`. If `B` is neither zero nor one, compute `s=C*A/B^2`, `d=B/A`, and `z=d*(H(s)+e)` for choice bit `e`; require the original quadratic, which also rejects a nonzero trace of `s`. If `B=0`, use its unique root `z=u1+u2`; if `B=1`, use its unique root `z=C`. Implement both exceptional branches with Boolean equality indicators and multiplexers, not a post-hoc filter. Require each of the four partial-sum `u` values nonzero, as in the parent. Keep the fifth S3 link to the selected frozen fiber unchanged. No known intermediate coordinate is pinned in either formula. An independent numerical control must check regular and both exceptional branches before the measured solver run.

Build one native-XOR XCNF per input, using the parent Karatsuba circuit and CryptoMiniSat 5.14.7 binary pinned in [CONFIG.json](CONFIG.json), one worker and seed zero. First profile and run the planted formula with only its six masks and fiber selector pinned; neither inverses nor partial sums may be pinned. The control bound is 100,000 conflicts and 30 seconds, with a 300-second formula-build bound and monitored 4 GiB RSS cap. A model must pass independent checked-Sage group replay. If the planted control does not return such a model, preserve the failure and do not attempt the ordinary target. If it passes, run the one frozen ordinary target once at 2,000,000 conflicts and 600 seconds with the same build and memory bounds. Preserve timeouts, OOMs, no-model statuses, raw XCNF and solver logs with hashes, exact source/binary/runtime receipts, formula size, query/build/solve/replay costs and all model checks. A timeout or `INDETERMINATE` is not UNSAT or a natural-yield estimate.

The comparison to the parent is *solver-stage diagnostic* on the same planted input, solver, and resource caps; formula size and implementation are the controlled change. If the planted control passes, an ordinary target attempt can establish only one bounded PDP outcome, not relation yield or matrix rank. Independently reconstruct each proposed mask, rational lift and sign assignment; verify the raw sum in its selected fiber and `[4]sum=Q`, and replay the public Q against its withheld fixture scalar outside the solver. All Sage jobs and runtime receipts use the checked repository launcher. The host is not isolated, so CPU times remain exploratory diagnostics. `candidate_id`, useful rank, complete one-target online time, verified logarithm and rho speedup stay `null` until a full pipeline is actually measured.
